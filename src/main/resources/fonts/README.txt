Optional: the Figma design uses the font "Inria Sans".
Download it free from Google Fonts, then copy these files into this folder:

    InriaSans-Regular.ttf
    InriaSans-Bold.ttf
    InriaSans-Light.ttf

The app finds them automatically. Without them it falls back to Segoe UI.
(The big GRUB EAST logo uses Impact, which already comes with Windows.)
